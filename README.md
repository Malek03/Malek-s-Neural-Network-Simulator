# محاكي الشبكات العصبية (Neural Network Simulator)

## نظرة عامة
مشروع متكامل ومحاكي تفاعلي يهدف إلى تبسيط وشرح مفاهيم الشبكات العصبية والتعلم العميق (Deep Learning). يأخذ هذا المشروع المستخدم في رحلة تعليمية شاملة تبدأ من الإلهام البيولوجي وتاريخ الذكاء الاصطناعي، وصولاً إلى بناء وتدريب نماذج متقدمة مثل الشبكات العصبية العميقة (DNN) والشبكات العصبية الالتفافية (CNN).

تم تصميم هذا المحاكي ليكون أداة بصرية وتفاعلية بالكامل، مما يسمح للمستخدمين برؤية العمليات الحسابية المعقدة وهي تحدث خطوة بخطوة أمام أعينهم.

## المميزات الرئيسية
- **محاكاة تفاعلية بالكامل:** إمكانية بناء الشبكات العصبية وتعديل طبقاتها ومراقبة تأثير التغييرات في الوقت الفعلي.
- **تعدد طرق الحساب:** يوفر المحاكي عرضاً للعمليات الحسابية باستخدام طريقة العقد (Nodes) وطريقة المصفوفات (Matrices) لتوضيح الجانب الرياضي للشبكات.
- **شرح خطوة بخطوة:** آليات العمل المعقدة مثل الانتشار الأمامي (Feedforward) والانتشار الخلفي (Backpropagation) مشروحة بالتفصيل.
- **نماذج معمارية متعددة:** دعم للشبكات العصبية العميقة (DNN) والشبكات العصبية الالتفافية (CNN).
- **مفاهيم تفاعلية:** أقسام مخصصة لشرح تاريخ الذكاء الاصطناعي والإلهام البيولوجي من الدماغ البشري لربط الجانب النظري بالعملي.
- **توليد البيانات:** أدوات مدمجة لتوليد بيانات تدريبية واختبار النماذج عليها.

## التقنيات المستخدمة
تم بناء هذا المشروع بالاعتماد كلياً على تقنيات الويب الأساسية دون استخدام إطارات عمل خارجية، لضمان سرعة الأداء وسهولة الوصول:
- **HTML5:** لبناء هيكل الصفحات والعناصر التفاعلية.
- **CSS3:** لتصميم واجهة المستخدم، الرسوم المتحركة، وتوفير تجربة بصرية حديثة.
- **JavaScript:** للتعامل مع المنطق الرياضي، بناء هياكل الشبكات، رسم العناصر، وإدارة التفاعلات الحية.

## هيكلية المشروع
يحتوي المشروع على المجلدات والملفات الرئيسية التالية:

- `index.html`: الصفحة الرئيسية للمشروع والتي تحتوي على واجهة المستخدم.
- `css/`: مجلد يحتوي على ملفات التنسيق لتصميم الواجهة.
- `img/`: مجلد يحتوي على الصور والرسومات.
- `js/`: مجلد يحتوي على ملفات المنطق البرمجي، ومقسم إلى وحدات لتنظيم الكود:
  - `main.js`: الملف الأساسي لإدارة التفاعلات العامة وتهيئة الصفحة.
  - `network-builder.js` و `network-renderer.js`: لبناء ورسم الشبكات العصبية.
  - `feedforward.js` و `backprop.js`: للعمليات الحسابية وتحديث الأوزان.
  - `cnn-builder.js` و `cnn-visualizer.js` و `cnn-architectures.js`: للتعامل مع الشبكات الالتفافية.
  - `dnn-builder.js` و `dnn-training.js`: لبناء وتدريب الشبكات العميقة.
  - `math-utils.js`: دوال رياضية مساعدة للعمليات الحسابية والتنشيط.
  - `data-generator.js`: لتوليد البيانات المستخدمة في التدريب.
  - `hero-animation.js` و `concepts-interactive.js`: لإدارة الرسوم المتحركة والتفاعلات التعليمية.

## طريقة التشغيل والاستخدام
لا يتطلب المشروع أي بيئة تشغيل خاصة أو تثبيت حزم برمجية. للبدء:
1. قم بتحميل أو استنساخ المشروع إلى جهازك المحلي.
2. قم بفتح ملف `index.html` باستخدام أي متصفح ويب حديث.
3. ابدأ في استكشاف الأقسام التعليمية أو انتقل مباشرة إلى قسم المحاكاة لبناء شبكتك الأولى.
